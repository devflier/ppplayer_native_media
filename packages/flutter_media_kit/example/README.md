# Android native playback example

Run `flutter pub get` and `flutter run` on an ARM64 Android device or x64 Android
emulator. Enter a media URL, press Open, and use the video controls. Network
playback needs the INTERNET permission included in the Android manifest. This
example uses the local package, without the original Android native provider.

Only Android is configured; this example does not establish other-platform
support or audible-output acceptance.
